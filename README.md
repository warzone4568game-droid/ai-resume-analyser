# AI Resume Analyzer Pro

A web app that analyzes resumes for ATS compatibility, job-role match, skill gaps, and areas for improvement. It includes a rule-based local mode that works without an API key.

## Features

- Paste resume text or upload a PDF
- Compare a resume with a target job role and optional job description
- View ATS and job-match scores, strengths, weaknesses, and recommendations
- Try the app with a sample resume
- Copy or download an analysis report
- Run locally without an API key
- Optionally enable Gemini-powered analysis with a server-side API key

> Local analysis uses rule-based checks. Scores and recommendations are estimates, not hiring advice.

## Requirements

- Node.js 18 or newer
